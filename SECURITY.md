# Security policy

PC Diag is a read-only tool that runs as a standard user. If you find a security issue (for example a way
to make it execute unexpected commands or leak credentials in a report), please report it privately with
[GitHub security advisories](https://github.com/Karobwe/pcdiag/security/advisories/new) rather than in a
public issue. You will get an answer within a few days.

Only the latest release receives security fixes.
